# Marquinhos Lanches

Landing page da lanchonete Marquinhos Lanches, em Registro – SP.

Site estático (HTML, CSS e JavaScript), sem instalação: abra `index.html`.

- Dados e fotos das seções: `js/config.js`
- Efeito de rolagem do hero: `js/movimento.js` e `imagens/scroll`
- Modo claro/escuro: `css/tema.css` e `js/tema.js`

## Publicar no GitHub Pages

Settings > Pages > Deploy from a branch > `main` / `(root)`.
